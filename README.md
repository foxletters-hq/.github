# foxletters-hq/.github

本仓库用于托管 **狐信科技（Foxletters）** GitHub 组织（[@foxletters-hq](https://github.com/foxletters-hq)）的公共门面主页与组织级社区规范文件：

- **[profile/README.md](./profile/README.md)**：展示在 [https://github.com/foxletters-hq](https://github.com/foxletters-hq) 组织首页的介绍页；
- **[CONTRIBUTING.md](./CONTRIBUTING.md)**：组织级默认贡献指南与 CLA 说明；
- **[SECURITY.md](./SECURITY.md)**：组织级安全漏洞报告指南；
- **`assets/`**：组织主页引用的品牌图标与角色头像资源。
